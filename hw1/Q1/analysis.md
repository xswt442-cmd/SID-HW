# Q1 随机质数生成与计数

## 方法

程序以学号 **2453721** 作为随机种子，在 `[2, 2³²)` 范围内拒绝采样，并用确定性 Miller–Rabin 判定候选数。每组生成 131072 个质数，共生成 16 组；随后按组号合并，并用 `wc -w` 统计分组文件与合并文件的词数。

## 结果

| 项目 | 结果 |
|---|---:|
| 分组数 | 16 |
| 每组质数数量 | 131072 |
| 合并文件词数 | 2097152 |
| 生成及合并用时 | 57 秒 |
| 词数校验 | YES |

分组文件和合并文件位于 `Q1/output/`。运行截图 `screenshots/pic1.png` 记录了执行脚本、分组计数、合并文件计数及校验结果。
